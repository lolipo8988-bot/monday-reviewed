# Monday, Reviewed in One Line

A program that writes a single-line review of Monday to `/output/entry.txt`.

The line reviews Monday like a bad booking: a 9 a.m. meeting that could
have been an email, 214 emails that couldn't, and coffee that quit early —
yet the reviewer is somehow booked again next week.

Run it:

```sh
python3 main.py
```
